01 · Storage

Everything your agents remember.In one place.

A searchable history of every agent session, across tools and projects. Switch agents any time; your history stays with you.

  • Capture sessions automatically through agent hooks
  • Import the session history you already have
  • Prompts, responses, tool calls and files touched
  • Upload through the CLI, the API or hooks
  • Export all of it, whenever you want
# share one session
$ flisk share 8f3a2c

# attach it to the pull request
$ flisk share 8f3a2c --pr 412
